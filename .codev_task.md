# CoDev Task: Refactor Pairing to QR Code Only & In-App QR Scanner

## Mục tiêu
Loại bỏ hoàn toàn cơ chế ghép đôi bằng mã 6 số (OTP code) có entropy thấp. Chuyển đổi 100% sang mã QR chứa payload mật mã bảo mật (256-bit AES key, pairId, TTL).
Thiết bị Nhận (Receiver) quét mã QR trực tiếp trong app bằng `mobile_scanner` với giao diện Soft Modern, viewfinder scan overlay, torch toggle và camera switch.

## Ràng buộc TUYỆT ĐỐI
- Sử dụng `fvm flutter ...` cho mọi lệnh.
- KHÔNG dùng `build_runner`, `freezed` hay code generation.
- Thư viện `mobile_scanner: ^7.4.2` và quyền camera đã được cấu hình trong `pubspec.yaml`, `AndroidManifest.xml` và `Info.plist`.
- Dùng màu theo `Theme.of(context).colorScheme.*` (không hardcode màu, ngoại trừ nền QR trắng tinh `Colors.white` để đảm bảo camera nhận diện tốt trong dark mode).
- Chạy `fvm flutter analyze` và `fvm flutter test` đến khi **0 issues** và **All tests passed** trước khi kết thúc.

## Chi tiết triển khai

### 1. `lib/features/pairing/data/models/pairing_payload_model.dart`
- Cập nhật `PairingPayloadModel`:
  - Thuộc tính:
    - `final String pairId;`
    - `final String sharedSecretBase64;`
    - `final int createdAt;`
    - `final int expiresAt;`
    - `final String code;` (giữ lại optional default `''` để không phá vỡ tương thích nếu có code cũ tham chiếu)
  - Thêm getter:
    `bool get isExpired => DateTime.now().millisecondsSinceEpoch > expiresAt;`
  - Thêm phương thức xuất dữ liệu QR JSON:
    ```dart
    String toQrData() {
      return jsonEncode({
        'v': 1,
        'pairId': pairId,
        'secret': sharedSecretBase64,
        'exp': expiresAt,
      });
    }
    ```
  - Thêm factory parse từ chuỗi QR:
    ```dart
    factory PairingPayloadModel.fromQrData(String rawData) {
      final map = jsonDecode(rawData) as Map<String, dynamic>;
      final pairId = map['pairId']?.toString() ?? '';
      final secret = map['secret']?.toString() ?? '';
      final exp = (map['exp'] is num) ? (map['exp'] as num).toInt() : 0;
      if (pairId.isEmpty || secret.isEmpty) {
        throw const FormatException('Mã QR không đúng định dạng ghép đôi.');
      }
      return PairingPayloadModel(
        pairId: pairId,
        sharedSecretBase64: secret,
        createdAt: DateTime.now().millisecondsSinceEpoch,
        expiresAt: exp,
      );
    }
    ```
  - Cập nhật `toMap()` và `fromMap()` tương ứng (hỗ trợ cả key `secret` và `sharedSecretBase64`).

### 2. `lib/features/pairing/data/services/pairing_service.dart`
- Trong `PairingServiceImpl`:
  - `generateSenderPairing()`:
    - Sinh 256-bit random key bằng `CryptoHelper.generateSecretKeyBase64()`.
    - `final pairId = 'pair_${DateTime.now().millisecondsSinceEpoch.toRadixString(16)}_${CryptoHelper.sha256Hash(sharedSecretBase64).substring(0, 8)}';`
    - `expiresAt = now + (10 * 60 * 1000);` (10 phút)
    - Trả về `PairingPayloadModel(pairId: pairId, sharedSecretBase64: sharedSecretBase64, createdAt: now, expiresAt: expiresAt, code: '')`.
  - Cập nhật xác nhận trên Receiver:
    - Thêm phương thức `Future<bool> confirmReceiverPairingFromQr(String qrData) async`:
      - Thử `PairingPayloadModel.fromQrData(qrData)`. Nếu bắt lỗi hoặc `payload.isExpired` → trả về `false`.
      - Lưu `receiver_pair_id` và `receiver_shared_secret` vào `SharedPreferences`.
      - Trả về `true`.
    - Giữ `confirmReceiverPairing(String data)` gọi tới `confirmReceiverPairingFromQr(data)`.

### 3. `lib/features/pairing/data/repositories/pairing_repository.dart`

- Trong `PairingRepositoryImpl.submitReceiverPairingCode(String code)`: chuyển tiếp tới `submitReceiverPairingQr(code)` để tương thích.

### 4. `lib/features/pairing/presentation/bloc/`
- `pairing_event.dart`:
  - Thêm `PairingSubmitReceiverQrEvent extends PairingEvent` nhận `final String qrData;`.
  - Giữ `PairingSubmitReceiverCodeEvent` kế thừa hoặc alias gọi logic tương đương.
- `pairing_bloc.dart`:
  - Đăng ký `on<PairingSubmitReceiverQrEvent>(_onSubmitReceiverQr);`.
  - Trong `_onSubmitReceiverQr`:

    - Nếu thất bại: `emit(state.copyWith(isLoading: false, errorMessage: 'Mã QR không hợp lệ hoặc đã hết hạn.'));`.
