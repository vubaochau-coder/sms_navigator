# CoDev Task: Implement End-to-End Relay (Decryption, Server Sync & Realtime Polling)

## Mục tiêu
Hoàn thiện 100% luồng chuyển tiếp tin nhắn OTP từ Máy Gửi (Sender) -> Server -> Máy Nhận (Receiver):
1. Giải mã AES-256-GCM trong Flutter (dùng package `cryptography: 2.9.0`) khớp 100% với mã hóa của Android Native (`OtpCrypto.kt`).
2. Đồng bộ phiên ghép đôi với Server (`POST /api/v1/pair/init` cho Sender, `POST /api/v1/pair/confirm` cho Receiver).
3. Máy Nhận tự động kéo tin nhắn OTP chờ nhận từ Server (`GET /api/v1/relay/pending/:pairId`), giải mã và nạp vào danh sách hiển thị trên Dashboard.
4. Cho phép người dùng tùy chỉnh Server URL (Server Settings Dialog) trên AppBar của cả Sender và Receiver Dashboard để dễ dàng test trên máy thật qua IP LAN hoặc Domain.
5. Cập nhật giao diện Sender & Receiver Dashboard theo chuẩn Soft Modern Theme (Dual Light/Dark, không hardcode `Colors.white`).

## Chi tiết triển khai

### 1. Giải mã AES-256-GCM trong `lib/core/utils/crypto_helper.dart`
- Thêm method giải mã:
  ```dart
  static Future<String> decryptAesGcm256({
    required String ciphertextWithTagBase64,
    required String ivBase64,
    required String secretKeyBase64,
  }) async {
    final fullBytes = base64Decode(ciphertextWithTagBase64);
    if (fullBytes.length < 16) {
      throw const FormatException('Ciphertext quá ngắn (thiếu GCM authentication tag).');
    }
    final iv = base64Decode(ivBase64);
    final secretKeyBytes = base64Decode(secretKeyBase64);

    final cipherTextBytes = fullBytes.sublist(0, fullBytes.length - 16);
    final macBytes = fullBytes.sublist(fullBytes.length - 16);

    final algorithm = AesGcm.with256Bits();
    final secretKey = await algorithm.newSecretKeyFromBytes(secretKeyBytes);
    final secretBox = SecretBox(cipherTextBytes, nonce: iv, mac: Mac(macBytes));

    final clearTextBytes = await algorithm.decrypt(secretBox, secretKey: secretKey);
    return utf8.decode(clearTextBytes);
  }
  ```
- Thêm method mã hóa (dùng cho unit test & kiểm thử chéo):
  ```dart
  static Future<Map<String, String>> encryptAesGcm256({
    required String plaintext,
    required String secretKeyBase64,
  }) async {
    final algorithm = AesGcm.with256Bits();
    final secretKey = await algorithm.newSecretKeyFromBytes(base64Decode(secretKeyBase64));
    final secretBox = await algorithm.encrypt(
      utf8.encode(plaintext),
      secretKey: secretKey,
    );
    final combinedCiphertext = Uint8List.fromList([
      ...secretBox.cipherText,
      ...secretBox.mac.bytes,
    ]);
    return {
      'ciphertext': base64Encode(combinedCiphertext),
      'iv': base64Encode(secretBox.nonce),
    };
  }
  ```

    - Lưu SharedPreferences như hiện tại.

### 3. Kéo tin Pending trong `ReceiverRepository` & `ReceiverBloc`
- Trong `lib/features/receiver/data/repositories/receiver_repository.dart`:
  - Thêm interface `Future<int> pollPendingOtps();`.
  - Trong `ReceiverRepositoryImpl`:
    - Thêm dependency `PairingService pairingService`, `ApiClient apiClient`, `DeviceApiService deviceApiService`.
    - Implement `pollPendingOtps()`:
      - Lấy `pairing = await pairingService.getReceiverPairing()`. Nếu null -> return 0.
      - Gọi `await deviceApiService.registerDevice()`.
      - Gọi `final res = await apiClient.get('/api/v1/relay/pending/${pairing.pairId}')`.
      - Parse danh sách `messages` từ `res`.
      - Với mỗi message:
        - `final decrypted = await CryptoHelper.decryptAesGcm256(ciphertextWithTagBase64: msg['encrypted_payload'], ivBase64: msg['iv'], secretKeyBase64: pairing.sharedSecretBase64)`.
        - Parse JSON: `{ sender, otp, timestamp, body }`.
        - Tạo `ReceivedOtpModel` (id: msg['message_id'] ?? uuid, sender, otp, timestamp, rawMessage: body).
        - Lưu qua `storageService.saveReceivedOtp(model)`.
      - Trả về số tin nhắn mới đã nhận.
- Trong `lib/features/receiver/presentation/bloc/receiver_event.dart`:
  - Thêm `ReceiverPollPendingOtpsEvent extends ReceiverEvent`.
- Trong `lib/features/receiver/presentation/bloc/receiver_bloc.dart`:
  - Xử lý `on<ReceiverPollPendingOtpsEvent>`:
    - `final newCount = await repository.pollPendingOtps()`.
    - Nếu `newCount > 0`: `final otps = await repository.fetchReceivedOtps(); emit(state.copyWith(otps: otps));`.
