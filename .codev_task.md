# CoDev Task: Pairing UI Redesign

## Mục tiêu
Viết lại UI màn hình ghép đôi (`PairingSenderPage` và `PairingReceiverPage`) theo Soft Modern design, hỗ trợ Light/Dark theme, thêm countdown timer và OTP input 6 ô riêng biệt.

## Ràng buộc TUYỆT ĐỐI (đọc kỹ trước khi viết bất kỳ dòng code nào)
- Đọc `AGENTS.md` ngay bước đầu tiên.
- KHÔNG dùng `build_runner`, `freezed`, hay code generation.
- KHÔNG thêm bất kỳ dependency mới nào vào `pubspec.yaml`.
- KHÔNG sửa `PairingService`, `PairingRepository`, `PairingPayloadModel`, `PairingBloc._onSubmitReceiverCode`, `PairingBloc._onGenerateSenderCode`.
- Luôn dùng `fvm flutter ...` (không bao giờ dùng `flutter ...` trực tiếp).
- Không hardcode màu sắc — dùng `Theme.of(context).colorScheme.*`.
- Không import `AppColors` trực tiếp trong các page (đã có theme system mới).
- Chạy `fvm flutter analyze && fvm flutter test` đến khi không còn error/warning trước khi kết thúc.

### 4. Viết lại PairingReceiverPage
File: `lib/features/pairing/presentation/pages/pairing_receiver_page.dart`

Yêu cầu UI:
- AppBar: title "Nhập Mã Ghép Đôi"
- Body (SingleChildScrollView):
  - Header icon: `Icons.phonelink_ring_outlined`, gradient secondary → primary
  - Title: "Kết Nối Thiết Bị" — `theme.textTheme.headlineSmall`
  - Subtitle: "Nhập mã 6 số hiển thị trên Thiết Bị Gửi."
  - **OTP Input 6 ô** (`_OtpInputRow` widget riêng biệt, StatefulWidget):
    - 6 `TextEditingController` và 6 `FocusNode` riêng biệt
    - Mỗi ô: TextField với `maxLength: 1`, `keyboardType: TextInputType.number`,
      `textAlign: TextAlign.center`, fontSize 24, fontWeight bold
    - Container mỗi ô: width 44, height 56, border-radius 12,
      border 2px `colorScheme.primary` khi focused, 1.5px `colorScheme.outline` khi không
    - `onChanged`: khi nhập 1 ký tự → auto-focus ô tiếp theo; khi xóa → focus ô trước
    - Khi ô cuối (index 5) nhận ký tự → gọi callback `onCompleted(String code)`
    - `onCompleted`: parent nhận `code` 6 ký tự → `context.read<PairingBloc>().add(PairingSubmitReceiverCodeEvent(code))`
    - Expose method `clear()` để reset tất cả ô về rỗng khi có lỗi
  - Nút "Xác Nhận Ghép Đôi": `FilledButton`, disabled khi `state.isLoading`
    Nút này chỉ hiển thị khi OTP chưa đủ 6 số (hoặc để làm fallback submit thủ công)
  - BlocConsumer listener:
    - `isSuccess` → SnackBar thành công → `Navigator.pushReplacement(ReceiverDashboardPage)`
    - `errorMessage != null` → SnackBar lỗi + gọi `clear()` trên OTP input
