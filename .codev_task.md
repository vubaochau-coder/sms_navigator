# TASK: Implement Dual Theme (Light/Dark Soft Modern) & Network ApiClient with Device Auth

## 1. Mục tiêu
Nâng cấp ứng dụng `sms_navigator`:
1. **Hệ thống Giao diện Soft Modern (Dual Theme Light & Dark):**
   - Thiết kế giao diện mềm mại, hiện đại với bo góc lớn (16-20px), màu sắc êm dịu, đổ bóng tinh tế.
   - Hỗ trợ đầy đủ cả `lightTheme` và `darkTheme` theo chuẩn Material 3.
   - Thêm `ThemeCubit` (kế thừa `Cubit<ThemeMode>` hoặc BLoC) để người dùng chuyển đổi Light/Dark linh hoạt (lưu lựa chọn vào SharedPreferences).
   - Thêm nút toggle Theme (icon Mặt trời / Mặt trăng) trên AppBar của màn hình `RoleSelectionPage`.
2. **Network Client & Tích hợp Device Registration:**
   - Bổ sung package `http: 1.3.0` (ghim cứng version chính xác, không dùng `^`).
   - Xây dựng `ApiClient` xử lý gọi HTTP REST API, quản lý baseUrl (mặc định `http://10.0.2.2:3000` cho Android emulator hoặc `http://127.0.0.1:3000`), tự động đính kèm header `Authorization: Bearer <device_token>`, xử lý timeout 10 giây và bắt lỗi mạng (`NetworkException`, `ApiException`, `UnauthorizedException`).
   - Xây dựng `DeviceStorageService`: Lưu trữ an toàn `device_id`, `device_token`, `server_url`.
   - Xây dựng `DeviceApiService`: Gọi `POST /api/v1/devices/register` và `PUT /api/v1/devices/fcm-token`.
   - Đăng ký các service vào `DependencyContainer` trong `lib/core/di/injection.dart`.

---

## 2. Phạm vi can thiệp (Target Files)
- `pubspec.yaml`: Thêm `http: 1.3.0` vào dependencies (chạy `fvm flutter pub get`).
- `lib/core/constants/app_colors.dart`: Bổ sung bảng màu Soft Modern cho cả Light và Dark Mode.
- `lib/core/theme/app_theme.dart`: Định nghĩa cả `lightTheme` và `darkTheme` chuẩn Material 3 (CardTheme bo góc 16-20px, AppBarTheme, ButtonThemes).
- `lib/core/theme/theme_cubit.dart` (Tạo mới): Quản lý state chuyển đổi theme Light/Dark.
- `lib/core/errors/failures.dart`: Bổ sung `ServerFailure`, `NetworkFailure`, `UnauthorizedFailure`.
- `lib/core/network/api_client.dart` (Tạo mới): HTTP client đa năng.
- `lib/core/services/device_storage_service.dart` (Tạo mới): Quản lý lưu device_id & device_token.
- `lib/features/device/data/services/device_api_service.dart` (Tạo mới): API service đăng ký thiết bị.
- `lib/core/di/injection.dart`: Khởi tạo và cung cấp `ApiClient`, `DeviceStorageService`, `DeviceApiService`.
- `lib/app.dart`: Tích hợp `ThemeCubit`, cung cấp `theme: AppTheme.lightTheme`, `darkTheme: AppTheme.darkTheme`, `themeMode: state`.
- `lib/features/role_selection/presentation/pages/role_selection_page.dart`: Thêm nút toggle theme trên AppBar.
- `test/widget_test.dart`: Đảm bảo test case kiểm tra giao diện chạy pass.
